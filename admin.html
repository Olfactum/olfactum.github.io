Panel de edición del catálogo · GitHub Pages

1. Conectar con GitHub

Este panel utiliza directamente la API de GitHub para guardar productos.json e imágenes. Solo una cuenta con permiso de escritura puede guardar cambios.

Seguridad: utiliza un token personal fine-grained limitado exclusivamente al repositorio olfactum.github.io, con permiso Contents: Read and write. No compartas el token con nadie ni lo agregues al repositorio. El token solo se mantiene en la memoria de esta pestaña; al cerrarla deberás introducirlo nuevamente. Este enlace de administración es público, pero editar requiere el token.

Sin conectar. Ingresa tu token y pulsa «Conectar y cargar catálogo».

2. Agregar o editar perfume

Presentaciones disponibles

Activa las opciones que vendas. Cada presentación puede tener su precio o decir “Consultar precio”. Si no vendes un formato, desmárcalo.

Familias olfativas

Selecciona una o varias familias. Sin selección, se usarán las notas escritas en la descripción.

Destacados y promociones

Los destacados aparecen primero cuando se usa el orden predeterminado.

Usa solo promociones reales y vigentes. No se descuentan precios automáticamente; modifica los precios de las presentaciones si corresponde.

Al guardar, la imagen se sube automáticamente a la carpeta images/ del repositorio. Si editas un perfume sin subir nueva imagen, conservará la anterior.

3. Perfumes en el catálogo (0)

Toca «Editar» para cargar un perfume y configurar sus presentaciones. «Eliminar» lo quita del catálogo, pero no borra la foto del repositorio.

Conecta GitHub para cargar los productos.

4. Novedades y Preventas

Edita el título, la descripción y hasta cuatro perfumes que aparecen en el banner de novedades. Las tarjetas usan la foto, el nombre y el estado de cada perfume guardado en el catálogo; al tocarlas se abre su ficha de compra. Los cambios se guardan en novedades.json.

Perfumes que quieres mostrar

Puedes dejar espacios vacíos para mostrar menos de cuatro productos. No se agregan promociones ni descuentos automáticamente.

Ver sección en la tienda ↗

5. Testimonios de clientes

Aquí tú eliges qué testimonios y fotografías publicar. Puedes añadir una foto de una entrega, una captura de mensaje (sin datos personales) o una imagen compartida por el cliente. Solo publica imágenes y palabras con autorización de quien las compartió. No se generan reseñas automáticamente.

Al guardar, se subirá automáticamente a la carpeta images/ de GitHub. Si editas un testimonio sin seleccionar otra imagen, conservará la que ya tenía.

Deja «Mostrar» sin marcar para guardar como borrador. Puedes ocultar o eliminar cualquier testimonio después.

6. Preventas y Lanzamientos

Agrega perfumes que todavía no están en el catálogo habitual. Puedes subir una foto, publicar sus condiciones de preventa, editar o retirar el lanzamiento. Estos perfumes se guardan en preventas.json, separado de productos.json.

Al guardar, la fotografía se subirá a images/ en GitHub. Si editas sin subir otra foto, se conserva la anterior.
